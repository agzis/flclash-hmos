## 文档约定

- 详细技术文档集中在 `docs/`；根 README 保留项目简介与导航，AGENTS 保留 AI 开发约束，不复制整套指南。
- 命令与行内源码路径默认相对仓库根目录执行；Markdown 链接相对所在文档，引用根目录文件时使用 `../`。
- 验收记录是特定构建与设备的历史观察，不是每个后续版本自动通过的证明。区分实测结果、已确认原因和未验证范围。
- 工程目录/构建步骤变动时，同步更新项目指南、架构图和入口链接；新增专题文档在本页登记。
- 不写入私密订阅地址、凭据或签名材料；许可证原文保留在根目录 `LICENSE`、`LICENSES/` 和依赖原位置，文档只链接/说明，不迁走上游通知。
